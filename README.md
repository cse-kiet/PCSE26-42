# 🧠 EmoHealth Nexus

> Bridging Emotional Intelligence with Health Prediction

EmoHealth Nexus is an AI-powered healthcare platform that analyzes emotional patterns and correlates them with potential physical and mental health conditions. The system helps in early detection of secondary diseases by combining emotion recognition, health data analysis, and predictive intelligence.

---

## 🚀 Features

- 😊 Emotion Detection & Analysis
- 🏥 Disease Correlation Prediction
- 📊 Health Risk Assessment
- 📈 Interactive Dashboard
- 🧾 Patient Health Records Management
- 🤖 AI-powered Prediction Engine
- 🔒 Secure Data Handling
- 📱 Responsive UI

## ⚙️ How It Works

1. User enters health-related information
2. System analyzes emotional behavior patterns
3. Backend processes health + emotion data
4. AI model predicts possible disease correlations
5. Dashboard displays health insights and reports

## Installation

### Clone Repository

```bash
git clone https://github.com/cse-kiet/PCSE26-42.git
cd PCSE26-42
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```
